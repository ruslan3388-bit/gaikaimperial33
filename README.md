# Гайка империи — индустриальная стратегия

Объединённый Telegram Mini App-прототип: idle-кликер «Гайка империи» + заводская стратегия «ЦЕХ».

## Последняя исправленная сборка

- [Гайка империи v0.4 — автономный HTML](releases/gaika-v0.4-save-offline.html): экспорт/импорт сохранения, до 8 часов офлайн-дохода, прогрессирующие заказы и исправленная работа интерфейса.
- Это отдельный проверенный релизный файл; `index.html` по-прежнему собирается из `game_core.js` и `app.js`.

## Игровой цикл
- Тапай по гайке, покупай прессы и автоматы, наращивай пассивный доход.
- Строй цепочку `руда → сталь → детали`, следи за энергосетью и расходами.
- Продавай ресурсы по меняющимся ценам или выполняй контракт на 3 детали.
- Конвейер усиливает доход и выпуск; контур автоматизации развивает добычу.

## Запуск
Открой `index.html` в современном браузере. Весь игровой код встроен в файл; для запуска в Telegram Mini App потребуется размещение на HTTPS и настройка Web App у бота. Прогресс сейчас хранится локально в браузере.

## Разработка и тесты
```bash
node --test game.test.js
node verify_project.js
python build_index.py
```

`game_core.js` — игровая модель; `app.js` — интерфейс и Telegram bridge; `index.html` — собранная автономная страница. `TEST_PLAN.md` — ручной сценарий тестирования.
